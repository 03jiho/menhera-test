# 멘헤라 지수 — 연애 성향 테스트

연애할 때 감정이 어디까지 흔들리는지, 16개의 장면으로 가늠해보는 인터랙티브 심리 테스트입니다.

🔗 **플레이하기**
- Vercel: https://menhera-test-smoky.vercel.app
- GitHub Pages: https://03jiho.github.io/menhera-test/

## 기능

- 16문항, 4축(의존도·집착도·감정기복·관심욕구) 구조. 각 선택지는 0~3점으로 채점되고, 축별 점수와 전체 점수(%)로 환산됩니다.
- 문항마다 선택지 순서가 매번 랜덤으로 섞여서, 다시 진단할 때마다 조금씩 다르게 느껴집니다.
- 전체 점수로 5단계 진단명(가벼운~심각한 멘헤라)이 나오고, 4축 중 가장 높은 두 축의 조합으로 6가지 유형(독점형·롤러코스터형·확인형·폭풍형·경계형·불꽃형) 중 하나가 정해집니다.
- 결과 화면에 유형별 설명과 조언, 총평과 원포인트 조언이 함께 표시됩니다.
- X / LINE 공유 버튼과 결과 텍스트 복사 기능이 있습니다.

## 기술

순수 HTML + CSS + Vanilla JS로 작성됐고 빌드 과정이 없습니다. 별도 서버 없이 `index.html` 파일 하나로 동작해요. 답변과 결과는 브라우저 안에서만 계산되며 서버로 전송되거나 저장되지 않습니다.
